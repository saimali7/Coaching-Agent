# Coaching Agent

TypeScript monorepo with a React frontend and an Express API.

- `apps/web` — Vite, React, TanStack Router (file-based routes) and TanStack Query
- `apps/api` — Express 5, Zod validation, in-memory session store

## Getting started

```bash
npm install
npm run dev
```

`npm run dev` starts both apps. The API listens on `http://localhost:3000` and the web app
on `http://localhost:5173`, which proxies `/api` to the API so there are no CORS issues in
development.

To run them separately:

```bash
npm run dev:api
npm run dev:web
```

## Scripts

| Command | Description |
| --- | --- |
| `npm run build` | Builds both apps |
| `npm run typecheck` | Typechecks both apps |
| `npm start` | Runs the compiled API |

## Configuration

Copy `.env.example` to `.env` and adjust as needed. `PORT` and `CORS_ORIGIN` configure the
API; `VITE_API_URL` points the web app at a non-default API origin.

## API

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/health` | Health check |
| `GET` | `/api/sessions` | List coaching sessions |
| `GET` | `/api/sessions/:id` | Fetch one session |
| `POST` | `/api/sessions` | Create a session |
| `DELETE` | `/api/sessions/:id` | Delete a session |

Sessions are stored in memory, so they reset when the API restarts. Swap
`apps/api/src/sessions/store.ts` for a real database when you need persistence.

## Notes

`apps/web/src/routeTree.gen.ts` is generated by the TanStack Router plugin and is committed
so typechecking works on a fresh clone. It is regenerated on every dev run and build.
